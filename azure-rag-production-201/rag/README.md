# Workspace RAG Production Azure

Ce README présente le scénario rag de production azure, l ordre de lecture du workspace et l artefact final `rag/grounded-answer.json`.

1. Ouvrez ce README.
2. Relisez `rag/config/retrieval-policy.json`.
3. Exécutez `python rag/scripts/produce_grounded_answer.py` pour produire l artefact JSON.
