## ⚠️ Why Starter Code Alone Is Not Enough to Pass the Certification

Downloading raw Python scripts will not guarantee a passing score on the Microsoft Azure AI-102 exam:

1. **Architectural Trade-offs**: The AI-102 exam tests your ability to design robust multi-region deployments, semantic hybrid search scoring, and content filtering policies.
2. **Production Incident Handling**: Scenario-based exam questions assess whether you know how to handle rate limits (429), quota scaling, and data privacy boundaries.
3. **Distractor Traps**: Passing requires distinguishing subtle differences in Azure resource configuration options under strict time limits.
